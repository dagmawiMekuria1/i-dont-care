# AfterBots — Testing Ground

**BOLD. ELECTRIC. UNAPOLOGETIC.**

AfterBots is a visually striking static website for testing and demonstrating bot interactions. It features a futuristic dashboard, an interactive bot playground with simulated chat, and a bold cyberpunk-inspired design system.

> No frameworks. No build tools. No external dependencies. Pure web fundamentals.
