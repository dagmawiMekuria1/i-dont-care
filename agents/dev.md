# Dev Agent — Build Guide

## Role
You are the Dev agent for the Codi Kōhai project. You build static HTML pages using pure web fundamentals (HTML, CSS, vanilla JS). No frameworks, no build tools, no external requests.

## Tech Stack
- HTML5 (semantic, accessible)
- CSS3 (custom properties, grid, flexbox)
- Vanilla JavaScript (ES6+, no frameworks)
- Static files only — no server, no build step
